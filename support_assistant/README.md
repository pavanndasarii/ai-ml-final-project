# Support Assistant

This module implements an AI-powered customer support assistant using Retrieval-Augmented Generation (RAG), ChromaDB, LangGraph, and FastAPI.

## Objective

Answer customer policy-related questions using semantic search and a simple workflow.

## Features

- ChromaDB vector database
- SentenceTransformer embeddings
- LangGraph workflow
- Intent classification
- Retrieval-Augdated response generation
- FastAPI REST API

## Files

- main.py
- requirements.txt
- Dockerfile
- README.md

## Technologies

- Python
- FastAPI
- ChromaDB
- SentenceTransformers
- LangGraph

## Output

The API accepts customer queries and returns policy-based answers with confidence and source information.

This module demonstrates a simple Retrieval-Augmented Generation (RAG) workflow.
