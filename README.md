# AI/ML Final Projects

A collection of practical projects developed during my Artificial Intelligence and Machine Learning training, covering data engineering, data analytics, machine learning, and AI-powered applications.

## Projects

### 1. Books Data Pipeline
An end-to-end data pipeline that collects book information through web scraping, cleans and transforms the data using Pandas, stores it in SQLite, and performs SQL-based analysis.

**Technologies:** Python, BeautifulSoup, Pandas, SQLite, SQL

[View Project](./data_pipeline/)

### 2. Titanic Data Analytics and Machine Learning
An exploratory data analysis and machine learning project using the Titanic dataset. Includes data preprocessing, visualization, classification models, model evaluation, and hyperparameter tuning.

**Technologies:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

[View Project](./analytics/)

### 3. SupportAI – Document Retrieval Assistant
An AI-powered support assistant designed to retrieve relevant information from a knowledge base and provide responses using semantic search and retrieval-based techniques.

**Technologies:** Python, Sentence Transformers, ChromaDB, LangGraph, FastAPI, Docker

[View Project](./support_assistant/)

## Repository Structure

- `data_pipeline/` – Web scraping, data cleaning, SQLite database, and SQL analysis
- `analytics/` – Exploratory data analysis, machine learning, and model optimization
- `support_assistant/` – AI-powered document retrieval assistant

These projects demonstrate practical experience in Python programming, data processing, exploratory data analysis, machine learning, model evaluation, and applied AI.
